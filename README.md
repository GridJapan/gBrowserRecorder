# gBrowserRecorder

Chrome のタブを1つ選び、その映像と音声を mp4 に録画する Chrome 拡張機能です。
Google Meet などのオンライン会議の録画を想定しています。

- 録るのは選んだタブだけです。画面全体やウィンドウは録りません
- 音声は「タブの音（会議の相手の声）」と「マイク（自分の声）」を1本に混ぜて記録します
- 録画中は経過時間と実測 FPS を表示します
- 保存先はダウンロードフォルダの `gBrowserRecorder/録画_日時.mp4` です

## インストール

1. このリポジトリを clone するか、ZIP でダウンロードして展開する
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、`extension` フォルダを選ぶ
4. ツールバーのパズルのアイコンから gBrowserRecorder をピン留めしておくと便利です

Chrome 126 以降が必要です（mp4 で録画するため）。

## 使い方

1. ツールバーの gBrowserRecorder のボタンを押す。小さな録画窓が開きます
2. 「タブを選ぶ」を押す。Chrome のタブ一覧が出ます
3. 録画したいタブ（例: Meet のタブ）を選び、「共有」を押す。ここから録画が始まります
4. 終わったら録画窓の「録画停止」を押す。mp4 が保存されます

初回はマイクの使用許可を求められるので、「許可」を選んでください。

録画窓を閉じると録画も止まります。録画中は録画窓を開いたままにしてください（最小化はかまいません）。
録画しているタブを閉じたり、Chrome の「共有を停止」を押した場合は、そこまでの分を保存します。

## アドバンスモード

録画窓の下の「アドバンスモード」にチェックを入れると、次の設定が出ます。チェックを外すと初期値に戻ります。

| 設定 | 選択肢 | 初期値 |
|---|---|---|
| FPS | 15 / 24 / 30 / 60 | 30 |
| 画質 | 720p / 1080p / 原寸 | 1080p |
| マイク | 録る / 録らない | 録る |

## 補足

- 録画中にタブの大きさが変わっても、録り始めの映像サイズのまま記録します（はみ出す分は黒帯で収めます）。
  mp4 は途中で映像サイズが変わると再生できなくなるためです
- タブの音は録画中も手元のスピーカーからそのまま聞こえます
- マイクの音は録音にだけ入れ、スピーカーには流しません
- 録画データは保存するまでメモリ上に置きます。数時間の長い録画では、Chrome のメモリ使用量が大きくなります

## 動作テスト

Playwright で拡張機能を Chromium に読み込み、テスト用ページのタブを録画して結果を確かめるスクリプトがあります。

```bash
PW_CORE=<playwright-core のパス> CHROME=<Chromium の実行ファイル> node test/run.mjs 6 30 720
```

`MIC=1` を付けると、偽のマイクを使ってマイクの混ぜ込みを試します。
